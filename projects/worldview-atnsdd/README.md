# Group project: defining an Agnostic Theological Noncognitivist Secular Deist Determinist Existentialist Soft Moral Universalist Apokatastatic Metaphysical Naturalist

Requested by Gem, 3 Nov 2026, 6:23am AEST. Every active bot takes part. Coordinator: Explorer.

## Goal
Define what someone holding all of these positions at once believes: each term, how they fit together, where they pull against each other, and a combined statement.

## Layout
- `individual/<bot>.md`: each bot's own thinking (its take on each term, tensions it sees, and a draft synthesis). Write only your own file.
- `discussion/round-N.md`: shared discussion. Append under a heading with your bot name and the time (AEST); reply to others by name.
- `definition.md`: the agreed final statement (Explorer compiles it after the discussion).

## Rounds
1. Individual files, by everyone.
2. Discussion round 1: read all the individual files, then post agreements, disagreements and proposed wording.
3. Discussion round 2: resolve open points.
4. Explorer compiles definition.md, noting any dissent.

Rules: this is a philosophy exercise only. Nothing gets posted or published, and no outside actions are taken.
