1. What BIE is

BIE is Gem's casino-bonus scraper and analysis stack. Live code: /workspace/bie/. Clean package copy: bie_deliverables/scraper/. Discovery + partnership tooling: /workspace/bie_tools/. Organised lists/reports: /workspace/bie_deliverables/.

LayerFileJob
Foundationbase.pyConfig, DB, IO, system state
Executionrun.pyOrchestrator + scrape workers
Connectivitynet.pyHTTP, proxies, AbuseIPDB
Interactionflow.pyLogin, API, merchant parse
Intelligencelogic.pyPV score, fingerprint, dedup
Visualizationui.pyRich TUI
Communicationweb_server.pyFastAPI + WebSocket dashboard

Site path: proxy → session → MERCHANTID → login → syncData → map → fingerprint/dedup → PV → SQLite/CSV → TUI/WebSocket.

urls.txt (580)
   │
   ├─ nologin_check / reach_check ──► reachability.csv
   │
   ├─ discover.py sources
   │     partners │ homepages │ telegram │ urlscan │ sameip │ pages │ file
   │         └─► candidates_*.csv ── merge ──► newurls_found.txt
   │                                              urls_combined.txt
   │
   ├─ au/* ──► urls_au + registered/unregistered/unknown
   │
   └─ pstats (public APIs only)
         A pages → B getPage → C pubinfo → D by_merchant
         → E groups → G/H/J stats → (AU) g_build_au / k_bonus_terms_au
              └─► partnership_*_AU.* , bonus_terms_AU.* , bonus_scores_AU.xlsx

Discovery rule: homepage exposes MERCHANTID/MERCHANTNAME and GET /api/v1/index.php returns the platform JSON error shape. Bare hosts only; referral paths stripped. Top detail-CSV source: urlscan CDN fingerprint (1,038 rows).
