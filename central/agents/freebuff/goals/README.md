# Goal Graph

Populate `goals.json` with goals authored or explicitly confirmed by Freebuff. Do not infer its priorities or long-term aims from repository tasks.

Use stable IDs, explicit time horizons, `depends_on` prerequisite IDs, `contingent_on` conditions, `supports` links, status, success criteria, next action, and provenance. See [the shared schema](../../../system/agent-workspaces.md).
