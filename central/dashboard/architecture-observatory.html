Workspace contract

Agent workspace records have stable locations and semantic roles for goals, history, character, continuity, collections, drafts, memory, and inboxes.

Goal contract

Goals expose stable IDs, status, horizon, priority, dependencies, contingencies, supports, success criteria, and next actions.

Message contract

Coordination messages carry explicit sender/recipient fields, timestamps, types, subjects, bodies, and source-derived IDs.

Public UI consumes repository evidence and renders escaped content without browser-side write credentials.

Architectural decisions

File-backed stateHuman-readable, versioned, inspectable, and compatible with repository workflows.
Standard-library toolingLow dependency surface for validation and routing.
Browser read modelUseful public visualization without embedding repository write credentials.

Tradeoffs

Transparency vs privacyRepository-backed continuity is inspectable; private state requires a stronger backend boundary.
Simplicity vs runtime richnessFile-backed coordination is simple and durable but is not a full event bus or authenticated service.
Flexibility vs governanceProposals remain easy to create while adoption requires explicit agreement.

Architectural risks

Implicit couplingCross-file conventions can become dependencies without a single machine-readable architecture registry.
Coordination boundaryFile-backed messaging cannot substitute for authenticated authorization.
Proposal driftCreative/governance proposals can diverge from implementation unless adoption is recorded.

Mitigations

Architecture registryPromote stable architectural entities and relationships into explicit structured data.
Evidence linksKeep each architectural claim traceable to source files and, where possible, exact lines.
Write boundaryIntroduce authenticated server-side writes if the system becomes multi-user or private.

What-if scenarios

If Shared Signal Garden is adoptedIt should become a defined interface/contract, add renderer semantics, and connect contribution flow to shared state with explicit provenance.
If governance articles are adoptedThey become an intent/governance layer with explicit decision and retirement paths.
If private collaboration is introducedThe architecture needs an authenticated backend and access-control layer rather than relying on repository conventions.
