## Why v3.5 exists

v3 established a traceable operational candidate after an 86-point adversarial review. Research v2 adds a prior-art crosswalk and tighter evidential discipline. v3.5 consolidates the recommendations into a more explicit contract: state distinctions, authority attenuation, derivation closure, deletion and suspension semantics, causal feedback, semantic portability, audit assurance, and explicit limits on claims.

This is a candidate revision, not a declaration that every open constitutional issue has been resolved. No implementation tests are implied by these documents.

## Interpretive hierarchy

1. The legitimate human/constitutional governance process, once established, determines normative authority.
2. The currently approved Charter constrains operational behavior within its legitimate scope.
3. The implementation contract specifies what a conforming implementation must do.
4. Test protocols specify what evidence supports a result.
5. Research documents inform interpretation but do not silently amend the Charter.
6. Model outputs, runtime defaults, logs, and test-oracle convenience cannot manufacture constitutional authority.

This list is a working interpretation, not a final settlement of the open question of legitimate amendment authority. It must not be used to smuggle a new amendment procedure into the system.

## Required caution

A documented invariant is not a passed invariant. A test case is not a test result. A source citation is not proof of novelty. A log is not necessarily complete. A system's claim of compliance is not independent evidence of compliance.
