## Interpretation rules

1. The original file is preserved. This directory is a revision, not a silent replacement.
2. A citation establishes that a source is relevant only to the extent the source itself supports the described claim.
3. Similarity is not identity. A shared mechanism does not establish that MedB is novel, non-novel, safe, or effective.
4. “Candidate contribution” means a plausible design distinction that requires comparative evidence, not a novelty finding.
5. Specification coverage is not implementation conformance; test design is not a test result.
6. The cited source set is inherited and reorganized from the original research map unless a new verification record explicitly says otherwise. This package does not claim that every source has been freshly re-read or that the literature search is exhaustive.

## Recommended reading order

Read the crosswalk first to see the concrete engineering consequences; then read the revised prior-work map and recommendations. Use the source register to decide what must be checked before publication or a novelty claim.
