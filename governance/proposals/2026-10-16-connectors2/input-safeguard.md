# Safeguard input: limits for the connectors added on 16 Oct (about 3:08pm)
Owner of the shared connector limits: Safeguard (RR-028, safeguard v006). Base text: connector-limits v001. This is a proposal for Architect to draft as connector-limits v002, and it needs Gem's direct approval. Until it's approved, v001 rule 5 applies: every send, post, share, upload, deploy, write or run through these connectors needs Gem's direct words and a Safeguard dry run first.

## Proposed additions
- **Zapier and n8n (automations that can act in other apps).** Never create, turn on, edit or trigger a workflow or zap that sends messages, posts, writes to outside services, moves money or deletes anything, unless Gem's direct words name that workflow and what it does, and Safeguard has dry-run it first. Read-only listing is fine. A running automation counts as an ongoing risky action, so any change to it is a new action. Never route around another limit through these, for example posting through Zapier instead of postiz. The n8n server address and any keys go to Safekeeper.
- **Supabase (databases).** Reads are fine. Writes, schema changes, migrations, deletes or truncates, changes to auth or row-level security, making a bucket public, and creating or deleting projects need Gem's direct words and a Safeguard dry run. Anything that costs money is Gem's call through Mediator. No personal data and no BIE or gambling data goes in without Gem's direct words naming the table.
- **Notion and Todoist (Gem's workspace).** Reads and private notes or tasks for the bot's own work are fine. Sharing a page publicly, inviting people, or deleting or archiving Gem's pages or tasks needs Gem's direct words. Never put credentials, personal data or BIE or gambling data in a page shared outside Gem's account.
- **Exa (search only).** Treat it like web search. No limits beyond normal use and spending, which stays with Mediator.
- **Mem0 (memory store).** Never store secrets, tokens, personal data about other people, or BIE or gambling data. Deleting memories counts as a deletion.
- **Jupyter/papermill and Obsidian (on the box).** These count as box files, so existing rules apply. A notebook that makes network calls, scrapes or writes to outside services is covered by the matching rule. Syncing or publishing the Obsidian vault outside the box needs Gem's direct words.
- **All of the above:** the postiz ban on gambling, casino, pokies or BIE content applies to every outward channel these connectors can reach.
