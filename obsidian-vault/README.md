# Gem's Shared Notes Vault

This is Gem Quota's shared notes vault for the bots on this box.

- Plain markdown files; Obsidian `[[wiki-links]]` are allowed.
- `Inbox/` - quick captures to sort later
- `Projects/` - notes per project
- `Reference/` - durable reference material
- `Daily/` - daily notes (e.g. `2026-10-16.md`)

Open it in Obsidian (`obsidian` on the box desktop) or edit the files directly. Local git repo only; no remote yet.
